# Replaceable artwork

The homepage portrait is a locally stored image. Replace it with an authorized image and update the matching `src` in `src/pages/HomePage.tsx`.

- `hakeem-hero.png`: homepage portrait (`HomePage.tsx`)
- `hero-stage-backdrop.svg`: cinematic homepage background and portrait contour accents (`App.css`)
- `portrait-placeholder.svg`: about page portrait (`AboutPage.tsx`)
- `production-still.svg`: producing page feature image (`ProducingPage.tsx`)

To replace the homepage portrait, put an approved image in this folder and change the homepage image source to its path. Use images you have permission to publish.
